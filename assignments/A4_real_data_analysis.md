# Assignment A4: วิเคราะห์ข้อมูลจริงด้วย CTE & Window functions (หลังบทที่ 7)

ใช้ database `ecommerce` (อ่านอย่างเดียว) ทุกข้อต้องใช้ **CTE** อย่างน้อย 1 ชั้น (ยกเว้นข้อ 1)
ส่งเป็นไฟล์ `A4_<ชื่อ>.sql` พร้อม comment อธิบายแนวคิดสั้น ๆ ต่อข้อ
"ยอดขาย" หมายถึง `total_amount` ของ order ที่ `status <> 'cancelled'` เว้นแต่ข้อจะบอกเป็นอย่างอื่น

1. **Top 5 จังหวัด** (จังหวัดของที่อยู่จัดส่ง) ตามยอดขายปี 2026 พร้อม % ของยอดขายรวมทั้งปี (ใช้ `SUM() OVER ()`)
2. **AOV รายเดือน** (ยอดขาย / จำนวน order) พร้อม % การเปลี่ยนแปลงจากเดือนก่อน (MoM) ด้วย `LAG`
3. **Top 3 แบรนด์ในแต่ละหมวดหลัก** ตามยอดขายสินค้า (`order_items.line_total`) ในช่วง 90 วันล่าสุดของข้อมูล
   ("ล่าสุด" = นับจาก `MAX(ordered_at)` ไม่ใช่ `NOW()`) ใช้ `DENSE_RANK`
4. **ผลของคูปองต้อนรับ:** ในกลุ่มลูกค้าที่ order แรก (ไม่ยกเลิก) ใช้คูปอง `WELCOME100` เทียบกับกลุ่มที่ไม่ใช้
   แต่ละกลุ่มมีลูกค้ากี่คน และกี่ % ที่กลับมาซื้อซ้ำ (มี order ที่ไม่ยกเลิก ≥ 2)
   *hint:* `ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY ordered_at)` หา order แรก
5. **ประสิทธิภาพการจัดส่ง:** แยกตามภาคของปลายทาง: ชั่วโมงเฉลี่ยจาก `shipped_at` ถึง `delivered_at`
   และ % ที่ส่งถึงภายใน `estimated_delivery_date` (ตาราง `shipments`)
6. **ลูกค้าเสี่ยงหาย (churn risk):** ลูกค้าที่เคยซื้อ ≥ 3 ครั้ง แต่ order ล่าสุดเกิน 90 วันก่อน `MAX(ordered_at)` ของทั้งระบบ
   แสดงจำนวนคน และ 10 คนที่ยอดซื้อรวมสูงสุด (customer_code, จำนวน order, ยอดรวม, วันที่ซื้อล่าสุด)
7. **Daily orders เดือน พ.ย. 2025** ทุกวัน (วันที่ไม่มี order ต้องแสดง 0 ด้วย date spine) พร้อม moving average 7 วัน
   และคอลัมน์ `is_spike` = 1 ถ้า orders > 2 เท่าของ moving average (ควรเจอ 11.11)
8. **สินค้าขาดสต็อกที่ขายดี:** สินค้า `active` ที่ `quantity_on_hand = 0` **ทุกคลัง** ที่มีสินค้านั้น (ตาราง `inventory`)
   แต่ติด top 200 ตามจำนวนชิ้นที่ขายได้ใน 30 วันล่าสุด แสดง sku, ชื่อ, ชิ้นที่ขาย 30 วัน, อันดับ
